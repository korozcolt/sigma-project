    1. Create `resources/views/livewire/articulador/coordinators.blade.php` as a class-based Volt component:
       ```php
       <?php

       use App\Enums\UserRole;
       use App\Models\User;
       use Livewire\Attributes\Url;
       use Livewire\Volt\Component;
       use Livewire\WithPagination;
       use function Livewire\Volt\{layout, with};

       layout('components.layouts::app', ['title' => 'Gestión de Coordinadores']);

       new class extends Component {
           use WithPagination;

           #[Url(as: 'q')]
           public string $search = '';

           public function updatingSearch(): void
           {
               $this->resetPage();
           }

           public function with(): array
           {
               $user = auth()->user();
               $query = User::role(UserRole::COORDINATOR->value)->withCount(['leaders as leaders_count']);

               if ($user->hasRole(UserRole::AREA_COORDINATOR->value)) {
                   $query->where('area_coordinator_user_id', $user->id);
               }

               if ($this->search) {
                   $query->where(function ($q) {
                       $q->where('name', 'like', "%{$this->search}%")
                           ->orWhere('email', 'like', "%{$this->search}%");
                   });
               }

               $coordinators = $query->latest()->paginate(15);

               $totalCoordinators = $query->clone()->count();
               $totalLeaders = $query->clone()->get()->sum('leaders_count');

               return [
                   'coordinators' => $coordinators,
                   'totalCoordinators' => $totalCoordinators,
                   'totalLeaders' => $totalLeaders,
               ];
           }
       }; ?>
       ```
       Note: no `UserRole::AREA_COORDINATOR->value` inline-namespace reference anywhere in the Blade markup below the script — always reference the unqualified `UserRole::AREA_COORDINATOR->value` via the `use App\Enums\UserRole;` already imported above (CLAUDE.md explicit-imports rule; RESEARCH.md's Anti-Patterns section flags the existing `leaders.blade.php`'s `\App\Enums\UserRole::...` fully-qualified Blade references as an inconsistent outlier NOT to imitate).
