`resources/views/livewire/articulador/create-coordinator.blade.php` (current, confirmed identical pattern to `create-leader.blade.php`):
```php
public bool $nameLocked = false;

public function updatedDocumentNumber(): void
{
    $this->nameLocked = false;
    if (blank($this->document_number)) { return; }

    $identity = app(IdentityLookupService::class)->findByDocumentNumber($this->document_number);
    if ($identity) {
        $this->name = preg_replace('/\s+/', ' ', trim("{$identity->nombre1} {$identity->nombre2} {$identity->apellido1} {$identity->apellido2}"));
        $this->nameLocked = true;
    }
}

public function unlockName(): void { $this->nameLocked = false; }
```
Blade: `<flux:input wire:model.blur="document_number" .../>`, `<flux:input wire:model.blur="name" ... :disabled="$nameLocked" />`, and `@if($nameLocked) <flux:button type="button" wire:click="unlockName">¿Nombre incorrecto? Editar manualmente</flux:button> @endif`.

`IdentityLookupService::findByDocumentNumber()` is a plain DB lookup against `NationalIdentityRecord` — no `Http::fake()` needed.

Route: `articulador.coordinadores.create` (confirmed in `routes/web.php`), requires role `area_coordinator` (or `admin_campaign`/`super_admin`).

Pest v4 Browser has no `blur()` method — use `$page->keys('document_number', 'Tab')` after `$page->type(...)` to fire a real blur event (per 19-RESEARCH.md Pitfall 4).
