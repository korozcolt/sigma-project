```blade
    </flux:navlist.group>

```
Flux's `:current` prop renders as `data-current` (confirmed via `vendor/livewire/flux/stubs/resources/views/flux/button-or-link.blade.php`). Because Blade's `ComponentAttributeBag::__toString()` sets `$value = $key` whenever a boolean attribute is `true`, an active item (`:current="true"`) renders `data-current="data-current"` — NOT `data-current="1"`. An inactive item (`:current="false"`) has NO `data-current` attribute at all (the bag skips `false`/`null` values entirely) — it is not rendered as `data-current="0"`. Pest v4 Browser: `assertDataAttribute(string $selector, string $attribute, string|int|float $value): Webpage` internally asserts `data-{$attribute}` — call as `assertDataAttribute($selector, 'current', 'data-current')` for the active item. For the inactive item, use `assertAttributeMissing(string $selector, string $attribute): Webpage` (confirmed in `MakesElementAssertions.php`) — call as `assertAttributeMissing($selector, 'data-current')` (this method takes the raw attribute name, unlike `assertDataAttribute` which prefixes it).

Filament's own panel nav item (`app/Providers/Filament/AreaCoordinatorPanelProvider.php`):

Filament's built-in `Dashboard` page nav item is registered automatically by `->pages([Dashboard::class, DiaD::class])`. Active state on the Filament panel's own sidebar is a `fi-active` class on the `<li>` (confirmed via `vendor/filament/filament/resources/views/components/sidebar/item.blade.php`), e.g.:
```blade
<li {{ $attributes->class(['fi-sidebar-item', 'fi-active' => $active, ...]) }}>
    <a {{ generate_href_html($url, ...) }} ...>{{ $slot }}</a>
</li>
```
Pest v4 Browser has `assertAttributeContains(string $selector, string $attribute, string|int|float $value): Webpage` (confirmed in `MakesElementAssertions.php`) — usable with a Playwright `:has()` selector, e.g. `assertAttributeContains('li:has(a[href="'.route(...).'"])', 'class', 'fi-active')`.
