<objective>
Add one export column per active metadata key to the four in-scope CSV/xlsx exports (Coordinadores, Líderes, Anotadores, Testigos), satisfying FILT-03, by reusing the exact same `withCurrentValueSelects()` query-level mechanism built in Wave 1 — no per-row N+1 queries, no PHP-side grouping.

Purpose: FILT-03 requires that operators downloading these four management exports see assigned metadata alongside the existing columns, without a separate lookup step. Reusing `withCurrentValueSelects()` (rather than re-deriving a second "current value" resolution) keeps the append-only latest-row semantics (Phase 16 D-09) identical between the on-screen tables (Plan 17-02) and the downloaded files.
Output: All four export classes gain an `activeMetadataKeys` property, apply the shared query helper inside `query()`, and append one heading + one mapped cell per active key.
</objective>
