<objective>
Wire the individual metadata-assignment section (built in plan 16-01) into all four Filament edit forms: `CoordinatorForm`, `LeaderForm`, `AreaCoordinatorForm` and `UserForm`. This is D-04 (assignment lives inside the already-existing edit forms, not a standalone resource or row action) and D-02 (superadmin can assign to any user in the active campaign, which is why `UserForm` is included).

Purpose: These four forms are the admin-panel half of D-05's "assignment capability must exist in 3 places". The coordinador and articulador panels are covered separately by plans 16-05/16-06 because Filament panels never load Flux CSS/JS and the two UI layers cannot share markup.
Output: Four one-line schema additions plus a Pest suite proving edit-only visibility and the write path.
</objective>
