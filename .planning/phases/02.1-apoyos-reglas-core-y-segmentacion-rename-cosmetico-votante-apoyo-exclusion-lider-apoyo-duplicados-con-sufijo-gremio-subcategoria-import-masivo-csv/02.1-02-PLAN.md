<objective>
Build the Gremio -> Subcategoria hierarchical catalog: two plain Eloquent models mirroring the existing `Department` -> `Municipality` pattern exactly, each administrable via a Filament Resource, with no campaign scoping (global catalog per D-09).

Purpose: D-04 requires this to be an admin-manageable catalog (not a hard-coded enum) because the list of gremios/subcategorías will grow over time. D-05 requires both fields to always be optional on `Voter`. D-09 requires the catalog to be shared across all campaigns, matching how `Department`/`Municipality` already work in this codebase.
Output: `Gremio`/`Subcategoria` models + migrations + factories + two new Filament Resources, CRUD-tested.
</objective>
