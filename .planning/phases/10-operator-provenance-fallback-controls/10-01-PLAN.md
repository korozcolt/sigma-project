<objective>
Make every voter's polling-place source (live / db_reconstruction / snapshot / manual) and its freshness timestamp visibly show up in the two places an operator scans lists and individual records: the Voters table and the Voter view (infolist) page. Add a table filter so an operator can isolate voters on any given source, including the three non-live (fallback) sources. This is display-only work reusing `PollingPlaceSource`'s existing Filament badge contracts (`HasColor`/`HasLabel`/`HasIcon`) — no new color/label mapping, no resolver changes.

Purpose: SRC-01 (every polling-place result visibly shows its source) and the filter half of SRC-05 (operator can view/filter the set of voters currently on fallback data) both become observably true from this plan.
Output: Updated `VotersTable.php` (badge column + resolved_at column + source filter), updated `ViewVoter.php` (badge entry + resolved_at entry), and new Pest coverage in `VoterResourceTest.php`.
</objective>
