## Spacing Scale

Declared values (must be multiples of 4) — inherited verbatim from the existing chart island (Phase 20/21), confirmed via `ChartCard.jsx`/`ChartTooltip.jsx` Tailwind classes:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, tooltip micro-padding (`pb-1`, `mt-1`) |
| sm | 8px | Tooltip vertical padding (`py-2`), compact gaps |
| md | 16px | `ChartCard` base padding (`p-4`) — default chart canvas inset |
| lg | 24px | `ChartCard` padding at `lg:` breakpoint (`p-6`) |
| xl | 32px | Reserved — not currently used inside the chart island, available for widget-level layout if a new grid arrangement is needed |
| 2xl | 48px | Reserved — page-level widget stacking gaps (Filament's own grid, outside this contract's direct control) |
| 3xl | 64px | Reserved — not expected to be needed by any Phase 22 widget |

Exceptions:
- `ChartTooltip.jsx`'s `mb-1.5`/`gap-1.5` (6px) — sub-grid micro-spacing already established in Phase 20/21 for the tooltip's internal label/row spacing. Inherited as-is; do not introduce new sub-4px/sub-8px values beyond this existing precedent.
- **VIZ-02 stacked-bar container** must tolerate an unbounded number of bars (D-06: all coordinators shown, no top-N truncation). The chart's outer wrapper must set `overflow-x-auto` with a `min-width` driven by bar count (e.g. `Math.max(100%, coordinatorCount * 56px)`) rather than compressing bars to illegibility at high coordinator counts. This is a spacing/layout exception specific to VIZ-02, not a global scale change.

## Typography

Declared for the React-rendered chart canvas (axis labels, tooltip, empty/error state, gauge stat). Filament's own widget heading/description chrome (rendered by Blade, outside the React island) is governed by Filament's panel theme and out of this contract's scope — new widgets set `getHeading()`/`getDescription()` text per the Copywriting Contract below, but their rendered typography follows Filament's existing section-heading styling unchanged.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 400 (regular) | 1.4 — axis ticks (`XAxis`/`YAxis` `tick={{fontSize: 12}}`), secondary/opacity-reduced text (`text-xs opacity-60`) |
| Body | 14px | 400 (regular) | 1.5 — tooltip row text, funnel stage `LabelList` text, empty-state body copy |
| Heading | 14px | 600 (semibold) | 1.3 — tooltip header row (`border-b` label), empty-state "Sin datos" heading, chart-internal emphasized values (tooltip numeric value, `font-semibold tabular-nums`) |
| Display | 24px | 600 (semibold) | 1.2 — gauge center stat number (`text-2xl font-semibold tabular-nums`, per 22-RESEARCH.md Pattern 3) |

Font sizes declared: **12px, 14px, 24px** (3 distinct values across 4 roles). Font weights declared: **400 (regular), 600 (semibold)** — exactly 2. Note: the existing `ChartTooltip.jsx` header uses `font-medium` (500) for its label row; new Phase 22 components should use the 400/600 pair above for consistency and not introduce a third weight — this is a forward-looking simplification, not a retroactive change to Phase 20/21 code.

All numeric values (chart tooltip values, gauge stat, axis counts) use `tabular-nums` and `formatNumber()` (`es-CO` locale formatting, already in `lib/formatters.js`) — reuse directly, no new formatter needed.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f4f6` (light) / `#0f0f10` (dark) | Chart canvas background — `ChartCard.jsx`'s `chartArea` class, applies to all 5 new widgets unchanged |
| Secondary (30%) | `rgba(255,255,255,0.95)` (light) / `rgba(24,24,24,0.90)` (dark) | Tooltip surface (`ChartTooltip.jsx`), plus Filament's own panel/card chrome surrounding the chart (white / zinc-900, unchanged Filament default) |
| Accent (10%) | `#f97316` (orange, matches Filament's `primary.500`) | Reserved for exactly: (1) the rank-0/largest segment in any ranked chart via `rankedMonochromeFill(0, ...)` — applies to VIZ-01's largest `VoterStatus` donut segment, VIZ-02's largest stacked-bar dataset call-out (if a single-series ranking is ever added), and the first/largest funnel stage in VIZ-03/VIZ-04; (2) the gauge's filled arc segment (`Cell fill="#f97316"` in `GaugeChart.jsx`, Pattern 3); (3) Filament's own primary-colored interactive chrome (buttons, active nav) — unchanged, outside this contract's new surface. Never apply accent to more than one segment/element per chart. |
| Destructive | `#dc2626`/`border-red-300 bg-red-50 text-red-700` (light) / `border-red-800 bg-red-950 text-red-300` (dark) | `ChartCard.jsx`'s existing `errorCard` treatment — reused verbatim by all 5 new widgets for the Phase 20 D-03 explicit-error-state requirement. No destructive user actions exist in Phase 22 (read-only widgets), so this role is scoped to load-failure error states only, not confirmation dialogs. |

Accent reserved for: the single largest/first-ranked segment or stage per chart (donut, funnel stages, any future ranked series), and the gauge's filled progress arc. Never used for body text, borders, or more than one segment per chart.
