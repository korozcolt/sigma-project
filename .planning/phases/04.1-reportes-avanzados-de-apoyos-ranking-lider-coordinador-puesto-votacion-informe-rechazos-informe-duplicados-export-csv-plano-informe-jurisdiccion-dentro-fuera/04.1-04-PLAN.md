    ```php
    public static function canView(): bool
    {
        $activeCampaign = CampaignContext::currentCampaign();

        if (! $activeCampaign) {
            return true;
        }

        if ($activeCampaign->scope === CampaignScope::Nacional) {
            return false;
        }

        // Regional scope is not auto-nulled by Campaign::boot() — hide only when there is
        // truly no territorial reference to compare against (both fields null).
        return ! (is_null($activeCampaign->municipality_id) && is_null($activeCampaign->department_id));
    }
    ```
    Prefer the `scope === CampaignScope::Nacional` enum comparison over an independent null-check, per D-04's recommended intent-clarity (RESEARCH.md confirms both are guaranteed equivalent by `Campaign::boot()`'s `saving()` hook for Nacional specifically).

    Table query — base it on real `Voter` rows (not a raw grouped aggregate) so each row has a stable primary key, and compute "Dentro"/"Fuera" per row via a `TextColumn` state closure rather than a SQL-level groupBy, to sidestep the missing-primary-key problem a grouped query would create for a Filament Table:
    ```php
    ->query(fn (): Builder => Voter::query()
        ->when($activeCampaign, fn ($q) => $q->where('campaign_id', $activeCampaign->id), fn ($q) => $q->whereRaw('1 = 0'))
        ->with('municipality'))
    ->columns([
        TextColumn::make('full_name')->label('Apoyo')->searchable(),
        TextColumn::make('municipality.name')->label('Municipio'),
        TextColumn::make('jurisdiccion')
            ->label('Jurisdicción')
            ->state(function (Voter $record) use ($activeCampaign): string {
                if (! $activeCampaign) {
                    return 'N/A';
                }
                if ($activeCampaign->municipality_id) {
                    return $record->municipality_id === $activeCampaign->municipality_id ? 'Dentro' : 'Fuera';
                }
                if ($activeCampaign->department_id) {
                    return $record->municipality?->department_id === $activeCampaign->department_id ? 'Dentro' : 'Fuera';
                }
                return 'N/A';
            })
            ->badge()
            ->color(fn (string $state): string => match ($state) {
                'Dentro' => 'success',
                'Fuera' => 'danger',
                default => 'gray',
            }),
    ])
    ```
    This branch order (`municipality_id` checked first, `department_id` second) naturally covers Regional-scope campaigns per RESEARCH.md's recommendation: if only `municipality_id` is set, compare municipally; if only `department_id` is set, compare by department; `canView()` already excludes the case where neither is set.

    ```php
    class ApoyosLideresCoordinadoresExport implements FromQuery, ShouldAutoSize, WithHeadings, WithMapping, WithStyles
    {
        use Exportable;

        public function __construct(protected ?int $campaignId = null) {}

        public function query(): Builder
        {
            return Voter::query()
                ->when($this->campaignId, fn ($q) => $q->where('campaign_id', $this->campaignId))
                ->with(['registeredBy.coordinator', 'municipality', 'neighborhood', 'gremio', 'subcategoria']);
        }

        public function headings(): array
        {
            return [
                'ID', 'Documento', 'Secuencia Duplicado', 'Nombre Completo', 'Teléfono', 'Email', 'Estado',
                'Municipio', 'Barrio', 'Gremio', 'Subcategoría',
                'Líder Nombre', 'Líder Teléfono', 'Líder Email',
                'Coordinador Nombre', 'Coordinador Teléfono', 'Coordinador Email',
            ];
        }

        public function map($voter): array
        {
            $registrador = $voter->registeredBy;
            $esCoordinadorDirecto = $registrador?->hasRole(UserRole::COORDINATOR->value) ?? false;
            $lider = $esCoordinadorDirecto ? null : $registrador;
            $coordinador = $esCoordinadorDirecto ? $registrador : $registrador?->coordinator;

            return [
                $voter->id,
                $voter->document_number,
                $voter->duplicate_sequence,
                $voter->full_name,
                $voter->phone,
                $voter->email,
                $voter->status->getLabel(),
                $voter->municipality?->name ?? 'N/A',
                $voter->neighborhood?->name ?? 'N/A',
                $voter->gremio?->name ?? 'N/A',
                $voter->subcategoria?->name ?? 'N/A',
                $lider?->name ?? 'N/A',
                $lider?->phone ?? 'N/A',
                $lider?->email ?? 'N/A',
                $coordinador?->name ?? 'N/A',
                $coordinador?->phone ?? 'N/A',
                $coordinador?->email ?? 'N/A',
            ];
        }
    }
    ```
