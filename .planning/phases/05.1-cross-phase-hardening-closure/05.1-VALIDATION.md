# Phase 05.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Pest v4.1 (`pestphp/pest ^4.1`, `pestphp/pest-plugin-laravel`, `pestphp/pest-plugin-browser`) |
| **Config file** | `tests/Pest.php` (standard Pest bootstrap; ~830 existing tests pass) |
| **Quick run command** | `php artisan test --filter=testName` or a specific file |
| **Full suite command** | `composer test` (runs `config:clear` then `artisan test`) |
| **Estimated runtime** | ~50-60 seconds (full suite, per 04.1-VERIFICATION.md baseline) |

---

## Sampling Rate

- **After every task commit:** Run the targeted `php artisan test --filter=...` for the specific gap being closed
- **After every plan wave:** Run `composer test` (full suite — protects the ~830 already-passing tests from regression)
- **Before `/gsd:verify-work`:** Full suite must be green (excluding the pre-existing, documented `UserResourceTest` flake — not this phase's scope)
- **Max feedback latency:** ~60 seconds
