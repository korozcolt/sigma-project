<objective>
Add a discreet secondary button "Actualizar datos desde Registraduría" next to the existing primary "Consultar Registraduría" suffixAction on the Voter (Apoyo) form's document_number field. Unlike the primary button (which uses the existing 3-layer cache: Redis -> DB reconstruction -> 2captcha), the new button force-bypasses the cache and always goes straight to a fresh 2captcha lookup, for cases where an operator needs to refresh already-resolved polling-place data for a cédula.

Purpose: give operators a way to force-refresh stale/incorrect polling-place data without touching the existing "1 paid lookup per cédula, then free from cache/DB" rule that the primary button already correctly implements.

Output:
- `HasRegistraduriaPolling::forceRefreshFromRegistraduria(string $cedula): void` — mirrors Layer 3 of `openRegistraduriaBrowser()` only (no Redis check, no DB reconstruction check)
- Second suffixAction on `document_number` in VoterForm.php: gray/discreet icon button (`heroicon-o-arrow-path`), visible only when `polling_place_id` is already filled, with a confirmation prompt (this always costs a paid 2captcha call)
- Manual E2E checkpoint deferred to the user (real cédulas + local Flask service required, cannot be automated in this environment)
</objective>

```php
/**
 * Force a fresh Registraduría lookup for a cédula, bypassing both the Redis
 * cache and the DB reconstruction fallback. Used by the secondary "Actualizar
 * datos" button when an operator explicitly needs to refresh already-resolved
 * polling-place data (e.g. after a Registraduría data correction).
 *
 * Always costs a paid 2captcha lookup — do not call this from any automatic
 * flow, only from an explicit user action with confirmation.
 */
public function forceRefreshFromRegistraduria(string $cedula): void
{
    if (blank($cedula)) {
        Notification::make()
            ->title('Número de documento requerido')
            ->body('Ingresa el número de cédula antes de actualizar.')
            ->warning()
            ->send();

        return;
    }

    try {
        $sessionId = app(RegistraduriaService::class)->startLookup($cedula);
        $this->registraduriaSessionId = $sessionId;
        $this->registraduriaOpen = true;
    } catch (\Exception $e) {
        Notification::make()
            ->title('Error al conectar con el servicio')
            ->body($e->getMessage())
            ->danger()
            ->send();
    }
}
```

No new imports needed — `Notification`, `RegistraduriaService` are already imported in this file.
