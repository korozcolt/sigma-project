<objective>
Fix the horizontal spacing between the "Saldos" topbar dropdown trigger and the adjacent "Cambiar" button by using an inline `style` attribute instead of the `ms-4` Tailwind utility class.

Purpose: A live browser investigation confirmed that horizontal-margin Tailwind utilities (`ms-*`, `ml-*`, `mr-*`, `m-*`) render `0px` in this app's currently-compiled CSS bundle — the CSS rules are present in the served stylesheet but do not take effect on computed style. Vertical margin (`mt-*`) and padding (`p-*`) work fine. This is why the previous two attempts (`ms-2`, then `ms-4`) failed visually: the class never produced any margin. Forcing `margin-inline-start` via an inline `style` attribute was confirmed to work.

Output: Updated `saldos-badge.blade.php` where the dropdown uses `style="margin-inline-start: 1rem"` instead of `class="ms-4"`.

Known pre-existing anomaly (NOT in scope): the broader Tailwind horizontal-margin-utility failure is an environment/build issue that likely affects other horizontal-margin utilities elsewhere in the codebase. Flag for a separate future investigation — do NOT audit or fix it here.
</objective>
