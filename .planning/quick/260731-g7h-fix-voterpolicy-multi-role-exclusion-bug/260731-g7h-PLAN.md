<objective>
Fix two confirmed production-blocking bugs surfaced while testing the consultacenso live-source integration. Neither bug is specific to consultacenso — both are pre-existing latent defects in general-purpose code.

**Bug 1 (authorization):** `VoterPolicy`'s mutating methods use an EXCLUSION check (`! $user->hasRole(REPORTS_VIEWER)`), which wrongly blocks any user who holds `reports_viewer` ALONGSIDE another elevated role (e.g. a `super_admin` who also has `reports_viewer` tacked on) from creating/editing/deleting Voters. Fix: rewrite to the INCLUSION pattern already established in `InvitationPolicy` (`hasAnyRole([...every role except REPORTS_VIEWER...])`).

**Bug 2 (frontend resilience):** `registraduria-browser.blade.php`'s Alpine polling loop treats ANY non-2xx HTTP response from `/registraduria/result/{id}` (including a transient 503/network hiccup while the Python microservice is still mid-lookup) as a definitive terminal error — it never checks `r.ok` before trusting the JSON body, so a missing `status` key on an error-shaped body collapses to `'error'` via `d.status ?? 'error'`, killing the modal and losing a lookup that would have succeeded moments later. Fix: check `r.ok` first, only escalate to a real error after ~15 CONSECUTIVE transient failures (~30s), and add an elapsed-time safety cap (~200s) using the already-existing `elapsed` counter. Genuine HTTP-200 `status:'done'`/`status:'error'` responses must keep working exactly as today.

Purpose: zero known bugs before deploying (explicit user requirement) — this quick task uses full mode (plan-check + verification) accordingly.

Output: Corrected `VoterPolicy` + regression test; resilient polling JS + genuine Pest v4 Browser test coverage.

**2a. Fix the Alpine polling logic.** In `resources/views/filament/registraduria-browser.blade.php`,
add a `transientFailures: 0,` property next to `error: null,` in the `x-data` object, and replace the
`start()` method's body with:

```js
start() {
    this.elapsed = 0;
    this.transientFailures = 0;
    this.elapsedInterval = setInterval(() => this.elapsed++, 1000);
    this.statusInterval = setInterval(() => {
        // Elapsed-time safety cap (~200s, comfortably past the Python service's own ~150s
        // hard 2captcha-solving bound) — independent of network state, checked first so it
        // always wins even if a fetch is also in flight.
        if (this.elapsed >= 200 && this.isSpinning()) {
            this.status = 'error';
            this.error = 'La consulta está tardando más de lo esperado. Intenta de nuevo más tarde.';
            this.stopAll();
            setTimeout(() => {
                this.isOpen = false;
                this._updateDisplay();
                window.Livewire.dispatch('registraduria-close');
            }, 3000);
            return;
        }

        fetch('/registraduria/result/' + this.sessionId)
            .then(r => {
                if (!r.ok) {
                    // Transient failure (503/network hiccup) — do NOT touch this.status,
                    // do NOT stop polling. Only escalate after ~15 consecutive failures
                    // (~30s at this 2000ms interval).
                    this.transientFailures++;
                    if (this.transientFailures >= 15) {
                        this.status = 'error';
                        this.error = 'No se pudo conectar con el servicio de Registraduría. Intenta de nuevo más tarde.';
                        this.stopAll();
                        setTimeout(() => {
                            this.isOpen = false;
                            this._updateDisplay();
                            window.Livewire.dispatch('registraduria-close');
                        }, 3000);
                    }
                    return null;
                }
                this.transientFailures = 0;
                return r.json();
            })
            .then(d => {
                if (!d) return; // transient failure already handled above, or cap already fired

                this.status = d.status ?? 'error';

                if (d.status === 'error') {
                    this.error = d.error ?? 'Error desconocido';
                    this.stopAll();
                    setTimeout(() => {
                        this.isOpen = false;
                        this._updateDisplay();
                        window.Livewire.dispatch('registraduria-close');
                    }, 3000);
                }

                if (d.status === 'done' && d.data) {
                    this.stopAll();
                    setTimeout(() => {
                        this.isOpen = false;
                        this._updateDisplay();
                        window.Livewire.dispatch('registraduria-result', { data: d.data });
                    }, 600);
                }
            })
            .catch(() => {});
    }, 2000);
},
```
