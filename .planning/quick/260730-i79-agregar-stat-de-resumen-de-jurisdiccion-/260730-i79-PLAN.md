D-1 (visibility): The new widget implements its OWN `canView()` mirroring `JurisdictionReportTable::canView()`
verbatim (duplicated logic). Investigation confirmed there is NO shared trait/base for this condition —
`app/.../.claude/skills/` and `.agents/skills/` do not exist, and every widget in `app/Filament/Widgets/`
owns its own `canView()`/query logic (no shared base beyond Filament's `StatsOverviewWidget`/`TableWidget`).
This is the existing codebase convention. Approach (a) chosen.

D-2 (counting): Counts use campaign-scoped DB-level counts, NOT in-memory voter loading.
- `total = Voter::where('campaign_id', $activeCampaign->id)->count()`
- `inside`:
  - if `municipality_id` set: `->where('municipality_id', $activeCampaign->municipality_id)->count()`
  - else if `department_id` set: `->whereHas('municipality', fn (Builder $q) => $q->where('department_id', $activeCampaign->department_id))->count()`
- `outside = total - inside` — deliberately `total - inside` (NOT a separate `!=` query) so parity with
  `JurisdictionReportTable` is exact: the table returns 'Fuera' for EVERYTHING not 'Dentro', including voters
  with a null `municipality_id`. `total - inside` reproduces that exactly.

D-3 (campaign scoping only, no role filtering): The widget scopes by `campaign_id` ONLY — it does NOT apply
`CampaignStatsOverview`'s leader/coordinator `scopedVoterQuery()` role narrowing. Rationale: this widget mirrors
`JurisdictionReportTable`, which uses a plain `Voter::query()->where('campaign_id', ...)` with no role scoping,
so the summary stats must match the numbers in the detail table sitting directly below it. Strict campaign
isolation is still honored via `CampaignContext::currentCampaign()` (exactly one active campaign).

D-4 (no drill-through url): The 2 stats get NO `->url()`. Verified against `VotersTable.php` filters
(campaign_id, status, polling_place_source, municipality_id, polling_place_id, neighborhood_id, registered_by,
contact_state, trashed): there is NO declarative filter that expresses "municipality matches the campaign's
target municipality/department" — jurisdiction is a runtime-computed comparison, not a stored column or a single
filterable value. Same reasoning the prior quick task 260730-hlg used to skip `->url()` on "Líderes Activos"
and "Progreso de Validación" in `CampaignStatsOverview.php`. No `->url()`, and this is intentional.

D-5 (sort + placement): `protected static ?int $sort = 8;` — the SAME sort as `JurisdictionReportTable` (the
detail table it summarizes), and registered in the `widgets()` array IMMEDIATELY BEFORE `JurisdictionReportTable::class`.
Filament orders equal-`sort` widgets by their position in the panel's `widgets()` array, so the summary stat renders
directly above its detail table — grouping the two jurisdiction widgets together. This is more meaningful than a
global "all stats at sort 0" placement, because this summary belongs specifically to the jurisdiction report.
(Existing sorts 0–9 are all taken; 7 = DuplicatesReportTable, 8 = JurisdictionReportTable, 9 = ApoyosLideresCoordinadoresTable.)

D-6 (read-only role): `reports_viewer` is read-only; this widget is informational only (no actions, no exports),
needs no policy changes. The reports panel already gates access via `EnsureUserHasRole:reports_viewer` in
`authMiddleware()` — registering the widget in the `widgets()` array is the only wiring needed, no per-widget role gate.

```php
<?php

namespace App\Filament\Widgets;

use App\Enums\CampaignScope;
use App\Models\Campaign;
use App\Models\Voter;
use App\Services\CampaignContext;
use Filament\Widgets\StatsOverviewWidget;
use Filament\Widgets\StatsOverviewWidget\Stat;
use Illuminate\Database\Eloquent\Builder;

class JurisdictionSummaryOverview extends StatsOverviewWidget
{
    protected static ?int $sort = 8;

    protected static ?string $heading = 'Resumen de Jurisdicción';

    protected static ?string $description = 'Apoyos dentro vs. fuera del territorio objetivo de la campaña';

    public static function canView(): bool
    {
        $activeCampaign = CampaignContext::currentCampaign();

        if (! $activeCampaign) {
            return true;
        }

        if ($activeCampaign->scope === CampaignScope::Nacional) {
            return false;
        }

        // Regional scope is not auto-nulled by Campaign::boot() — hide only when there is
        // truly no territorial reference to compare against (both fields null).
        return ! (is_null($activeCampaign->municipality_id) && is_null($activeCampaign->department_id));
    }

    protected function getStats(): array
    {
        $activeCampaign = CampaignContext::currentCampaign();

        if (! $activeCampaign) {
            return [
                Stat::make('Dentro del Territorio', 0),
                Stat::make('Fuera del Territorio', 0),
            ];
        }

        $total = Voter::query()->where('campaign_id', $activeCampaign->id)->count();
        $inside = $this->insideCount($activeCampaign);
        $outside = $total - $inside;

        return [
            Stat::make('Dentro del Territorio', number_format($inside))
                ->description('Apoyos en el territorio objetivo')
                ->descriptionIcon('heroicon-m-map-pin')
                ->color('success'),
            Stat::make('Fuera del Territorio', number_format($outside))
                ->description('Apoyos fuera del territorio objetivo')
                ->descriptionIcon('heroicon-m-map-pin')
                ->color('danger'),
        ];
    }

    private function insideCount(Campaign $activeCampaign): int
    {
        if ($activeCampaign->municipality_id) {
            return Voter::query()
                ->where('campaign_id', $activeCampaign->id)
                ->where('municipality_id', $activeCampaign->municipality_id)
                ->count();
        }

        if ($activeCampaign->department_id) {
            return Voter::query()
                ->where('campaign_id', $activeCampaign->id)
                ->whereHas('municipality', fn (Builder $query): Builder => $query->where('department_id', $activeCampaign->department_id))
                ->count();
        }

        return 0;
    }
}
```
