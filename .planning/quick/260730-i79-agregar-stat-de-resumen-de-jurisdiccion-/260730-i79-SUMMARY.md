## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed fatal "Cannot redeclare non static property" error from the plan's literal widget code**
- **Found during:** Task 2, first `php artisan test` run against the widget created in Task 1
- **Issue:** The plan's exact `JurisdictionSummaryOverview.php` content (copied verbatim per the plan's "Create ... with EXACTLY this content" instruction) declared `protected static ?string $heading` and `protected static ?string $description`. Filament v4's `Filament\Widgets\StatsOverviewWidget` base class declares these same properties as **non-static** instance properties (`protected ?string $heading = null;`), and PHP fatal-errors on a static/non-static property redeclaration mismatch in a subclass. Every sibling widget in this codebase (`FollowUpBacklogOverview`, `FallbackSourceOverview`, `DiaDStatsOverview`) already uses the correct non-static form.
- **Fix:** Changed both properties to non-static, matching the base class and every existing sibling widget's convention.
- **Files modified:** `app/Filament/Widgets/JurisdictionSummaryOverview.php`
- **Verification:** `php artisan test tests/Feature/Filament/JurisdictionSummaryOverviewTest.php` — all 4 tests pass (previously fatal-errored before every test).
- **Committed in:** `a6ffa40` (Task 2 commit)
