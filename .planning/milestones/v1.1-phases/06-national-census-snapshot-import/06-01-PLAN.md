<objective>
Load the 216,527-row national census snapshot (`database/external-data/censo_decoded_202310210734.csv`) into a new cédula-indexed `national_census_records` reference table, enriched with a `polling_place_id` FK resolved at import time via the divipol join against the seeded `polling_places`. The `census:import-national` command streams the ISO-8859-1 file, upserts idempotently (last-row-wins on duplicate cédulas), and reports the unmatched divipol percentage on completion without ever aborting.

Purpose: Delivers CENSO-02 (indexed, cédula-queryable, location-enriched snapshot table) and CENSO-03 (validate divipol codes against `polling_places` and report the unmatched %). This is the last-resort fallback data source Phase 8's `PollingPlaceResolver` will read from. It does NOT wire the snapshot into any lookup cascade and builds NO UI.
Output: A migration, the `NationalCensusRecord` model + factory, the `census:import-national` Artisan command, and a Pest feature test with an ISO-8859-1 fixture.
</objective>
