## Files Created/Modified
- `app/Filament/Widgets/RejectionsReportTable.php` - TableWidget consolidating VoterStatus rejection states and CallResult rejection outcomes into one row per voter via `orWhereHas('verificationCalls', ...)` (EXISTS subquery, never a join)
- `app/Exports/RejectionsExport.php` - `FromQuery`/`WithMapping` export mirroring the widget's query and `motivo` computation
- `app/Filament/Widgets/DuplicatesReportTable.php` - TableWidget showing every sibling (any campaign) of a document_number group that touches the active campaign; `withoutGlobalScopes()` + `withTrashed()`, per-row `campaign.name` badge, class-level PHPDoc flagging the D-06 exception
- `app/Exports/DuplicatesExport.php` - `FromQuery`/`WithMapping` export replicating the same two-step cross-campaign query, self-resolving `CampaignContext::currentCampaign()` with no constructor parameter

## Decisions Made
- DuplicatesExport intentionally has no `$campaignId` constructor argument (unlike every other export in this phase) — it resolves the active campaign internally so the export can never accidentally be scoped narrower than the widget it mirrors.
- The `motivo`/rejection-reason list uses `array_unique` before `implode(' / ', ...)` so a voter that is both status-rejected AND call-rejected for the exact same underlying reason string is not shown with a duplicated label.
