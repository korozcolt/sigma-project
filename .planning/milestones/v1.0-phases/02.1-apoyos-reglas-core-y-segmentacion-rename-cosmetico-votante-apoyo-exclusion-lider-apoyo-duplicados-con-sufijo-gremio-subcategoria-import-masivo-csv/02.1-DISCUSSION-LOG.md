## Alcance del rename Votante→Apoyo

| Option | Description | Selected |
|--------|-------------|----------|
| Apoyo en todo, siempre | Reemplaza "Votante" por "Apoyo" en absolutamente toda la UI: navegación, formularios, reportes, exports, notificaciones. | ✓ |
| Apoyo en gestión, Votante en censo/Registraduría | "Apoyo" en pantallas de gestión de campaña, pero se mantiene "Votante" donde se habla del cruce con el censo electoral real. | |

**User's choice:** Apoyo en todo, siempre.
**Notes:** Un solo término en todo el sistema, sin excepciones para el módulo de Registraduría.

## UX y auditoría de duplicados

| Option | Description | Selected |
|--------|-------------|----------|
| Alerta explícita antes de guardar | El formulario avisa "esta cédula ya existe, se guardará como duplicado en disputa" y pide confirmar. | ✓ |
| Guardado silencioso, sin fricción | Se guarda directo con el sufijo automático, sin alertar al operador. | |

**User's choice:** Alerta explícita antes de guardar.

| Option | Description | Selected |
|--------|-------------|----------|
| Sí, nota obligatoria | El admin debe escribir un motivo al reasignar el dueño de un duplicado. Queda en el historial junto con quién y cuándo. | ✓ |
| No, solo registro automático | Se guarda automáticamente quién hizo el cambio y cuándo, sin pedir nota manual. | |

**User's choice:** Sí, nota obligatoria.
**Notes:** Sostiene el "debate interno" que menciona el cliente con trazabilidad completa.

## Modelo de Gremio/Subcategoría

| Option | Description | Selected |
|--------|-------------|----------|
| Jerárquico | Cada Subcategoría pertenece a un Gremio específico (ej. PAE/ESE solo bajo Manipulador de Alimentos). Catálogo administrable en Filament. | ✓ |
| Independientes / combinación libre | Gremio y Subcategoría son dos campos sueltos sin relación obligatoria entre sí. | |

**User's choice:** Jerárquico.

| Option | Description | Selected |
|--------|-------------|----------|
| Obligatorio en nuevos, opcional en existentes | Todo apoyo creado/importado desde ahora debe traer Gremio+Subcategoría. Los existentes quedan "Sin clasificar". | |
| Opcional siempre | Gremio/Subcategoría quedan opcionales tanto para nuevos como existentes. | ✓ |

**User's choice:** Opcional siempre.

## Manejo de errores en import CSV

| Option | Description | Selected |
|--------|-------------|----------|
| Procesar válidas + reporte de rechazadas | Las filas válidas se importan; las inválidas quedan en un reporte descargable con el motivo del rechazo. | ✓ |
| Todo o nada | Si cualquier fila falla, se aborta el archivo completo. | |

**User's choice:** Procesar válidas + reporte de rechazadas.

| Option | Description | Selected |
|--------|-------------|----------|
| Solo Admin de campaña / Super Admin | El import es una operación centralizada. | ✓ |
| Admin y Coordinador (acotado a su propia gente) | Un coordinador también puede importar, acotado a sus propios líderes. | |

**User's choice:** Solo Admin de campaña / Super Admin.
