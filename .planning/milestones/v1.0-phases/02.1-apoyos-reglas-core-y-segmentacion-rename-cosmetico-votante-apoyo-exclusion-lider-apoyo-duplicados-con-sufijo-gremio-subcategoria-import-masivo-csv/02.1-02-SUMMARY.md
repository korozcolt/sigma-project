# Phase 02.1 Plan 02: Gremio/Subcategoria Catalog Summary

**Global Gremio -> Subcategoria hierarchical catalog with full Filament CRUD, mirroring the existing Department/Municipality pattern exactly, no campaign scoping.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 3 completed
- **Files modified:** 19 (18 created, 1 modified)

## Accomplishments
- `Gremio` and `Subcategoria` Eloquent models with `HasMany`/`BelongsTo` relations, migrated into the database as global catalogs (no `campaign_id` anywhere, per D-09)
- `restrictOnDelete()` FK constraint on `subcategorias.gremio_id` prevents accidental orphaning of classification data referenced by existing Voters
- `GremioResource` and `SubcategoriaResource` give admins full CRUD from the Filament panel with zero code changes needed to add new gremios/subcategorias (D-04)
- `SubcategoriaForm` uses a searchable, preloaded `gremio_id` select via `relationship()`, so subcategorías are always tied to exactly one gremio
- `tests/Unit/Models/GremioSubcategoriaTest.php` fully green (4 passing, 1 intentionally skipped pending plan 02.1-08's `voters.gremio_id`/`subcategoria_id` columns)
