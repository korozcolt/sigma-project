<objective>
Rename every remaining "Votante"/"votante" occurrence in the Filament admin panel surface (Pages, Widgets, non-Voter Resources) to "Apoyo"/"apoyo", per the locked D-01 decision: the rename applies to the whole UI, without exception, no matter which resource displays voter-related text.

Purpose: D-01 says "Apoyo" replaces "Votante" everywhere in the UI: navigation, forms, reports, exports, notifications, no exceptions. `app/Filament/Resources/Voters/*` (the Voter resource's own files) is intentionally OUT of scope here; it is renamed together with its functional changes in plan `02.1-09` to avoid two plans editing the same file. This plan covers every OTHER Filament admin-panel file that mentions "votante".
Output: ~20 Filament admin-panel PHP/Blade files plus `lang/es/models.php` renamed; 3 existing tests updated to match the new text.
</objective>
